# Analytic units, alignment and provenance

The harmonized study table is [integrated_mo_analytic.csv](../data/processed/integrated_mo_analytic.csv). Its grain is **one selected Missouri FSIS primary poultry sample**, retaining the source sample identifiers. Each row has an outcome date and an analytic origin seven calendar days earlier. This permits a bounded retrospective seven-day-lead comparison without inventing outbreak labels or assigning airport weather to a particular establishment. It is not a prospective forecast or a probability of consumer illness.

The reproducible pipeline is `python scripts/train_integrated_study.py`. Its exact filtering, folds, coefficients and ablations belong in [the integrated study](../reports/integrated_model_study.md), [evaluation JSON](../reports/integrated_model_evaluation.json) and [time-series export](../reports/integrated_model_timeseries.csv). The national sample-level feasibility model and earlier-snapshot timing study are separate experiments with different denominators and must remain separately labeled.

The recorded export retains 1,534 selected Missouri samples from 16 establishments, including 1,044 rows with explicit incomplete-coverage reasons. Only 490 have complete integrated coverage. The primary chronological comparison uses 255 training samples and 171 held-out samples, including 22 positives. Retaining excluded rows makes the substantial coverage selection visible; it does not correct its bias.

## Common analytic keys and clocks

| Layer | Original grain / geography | Alignment rule and available history | Boundary |
|---|---|---|---|
| FSIS primary outcome | Selected raw-poultry laboratory sample; establishment state and collection date | Select MO, noncanceled Positive/Negative primary outcomes. Outcome date = collection date; origin = outcome date minus seven days. Sample identity remains attached. | Selected surveillance is not representative of all poultry; no secondary typing or illness labels are pooled. |
| FSIS historical feature | Earlier selected primary samples | Only samples whose assumed collection-date + 90 days is at/before origin may contribute to lagged prevalence; calendar season terms use the known origin. Retain the latest allowable collection date. | The 90-day lag is an assumption; snapshot creation is not verified first public availability. |
| PulseNet-derived BEAM feature | State × calendar month × source/site × pathogen × serotype | Select MO, Human and Salmonella explicitly. Preserve source-category denominators; aggregate selected monthly isolate counts and use the study's specified lagged period with assumed availability at month end + 90 days. Keep observation-period and assumed-availability dates. | Human isolates are not FSIS tests, unique patients, matched outbreaks or a poultry-specific exposure outcome. Unknown jurisdiction codes are not mapped to MO. |
| NOAA environmental feature | Five Missouri airport stations × daily provider reporting-period label | At each origin, form a trailing 28-day ambient window ending seven days before origin. Apply the study's numeric/quality requirements and explicit equal-station summary; retain window endpoints and coverage. Use TMAX/TMIN in °C and PRCP in mm from metric-unit requests. | The state ambient index is an ecological covariate, not establishment/cargo exposure. Seven days is an assumed availability buffer; actual publication time remains unknown. |
| NORS additional feature | Historical outbreak report; jurisdiction, year and month | Select Missouri, Food transmission mode and case-insensitive etiology containing Salmonella. Use log(1 + trailing 12-month exported-record count) with assumed month-end + 730-day availability; retain period-end/availability dates. Periods are capped at the observed source end, never extended with future zeros. | NORS input ends in 2023. Within the source window, no matching exported row is a zero count of matching records, not evidence of no outbreak. The 730-day lag is an assumption, not provider metadata. |
| USDA ERS additional context | County/county-equivalent × measure-specific vintage | Keep five-character FIPS and original definitions. Ten Missouri measures have 2019/2020/2023 vintages and different person/household/store denominators. They remain a separate table. | No honest mapping exists from fictional recipients to counties; historical access cannot be presented as current shipment need or as an FSIS safety label. |
| FSIS establishment directory | Missouri establishment point / directory snapshot | Retain official identifiers and coordinates for context. A numeric identity alone is insufficient for an unreviewed relationship to simulated lots. | Directory geography is not a verified supply contract or an as-of exposure location. |
| Operational network | Seeded lot, shipment, truck, destination and simulated event | Fixed simulation clocks, IDs, six-hour wave and measured source retrieval times remain separate. Human review applies operational hard constraints. | Model study dates and real-time interaction clocks do not turn simulated cargo or deliveries into observations. |

For NOAA, provider daily labels can reflect local observation periods. They are not converted into a claim of local-midnight or UTC equivalence. The dictionary preserves original `*_ATTRIBUTES`; trace, missing, quality flags and measurement error are not interchangeable. The recorded coverage window has 2,730 returned station/day rows, but nine missing PRCP values, so row coverage does not imply complete metric coverage. Only the five stations selected in `reports/noaa_coverage.json` enter this description; another response file on disk does not silently expand the study.

No new state-to-county, HHS-region-to-county or shipment-to-station cross-walk is invented. The integrated model uses an explicit MO ecological key. NORS' Missouri name is selected separately from BEAM/FSIS `MO`; names and codes are not blindly merged. Broader national CDC summaries, multi-state categories, BEAM food/animal/environment strata and the older multi-year burden summaries remain separately inspectable evidence.

## Dictionary, provenance and reproduction

Run `python scripts/build_data_dictionary.py` after the source adapters and model pipeline. Optional `--output-root PATH` writes a review copy without changing input tables. The command creates [data_dictionary.csv](../reports/data_dictionary.csv), [source_provenance.csv](../reports/source_provenance.csv) and [source_provenance.json](../reports/source_provenance.json). It reads and hashes the same byte snapshots it parses, verifies current source-table hashes against the ingestion manifests, records actual row/column/null counts, and copies the recorded original filenames/hashes into lineage. It does not train a model, refresh a provider, modify supplied raw files or open an operator database. Original-file lineage hashes are copied from the earlier ingestion reports; this is not a new authenticity or completeness claim.

The source inventory is [inventory.json](../data/manifests/inventory.json). CDC and directory lineage is [evidence_manifest.json](../data/processed/evidence_manifest.json); FSIS lineage is [fsis_provenance.json](../data/processed/fsis_provenance.json). The [USDA ingestion report](../reports/usda_food_environment.json) includes variable definitions, source locations, raw missing codes and output hash. The [NOAA coverage report](../reports/noaa_coverage.json) retains request URLs, retrieval times, response hashes, stations and variable-level coverage. Public-stream fixtures and simulated inputs remain separately labeled in [the catalog](data_catalog.md) and [simulation assumptions](simulation_assumptions.md).

Missing numeric values stay missing. USDA suppressed/unavailable codes become null with exact source-cell evidence retained; missing is never interpreted as measured zero. BEAM original formatted strings remain in their source tables and are parsed only by the explicit feature adapter. A text value can be non-null but analytically unusable, so dictionary null counts are not claims of analytic completeness.

Unresolved limits include assumed availability lags, retrospectively downloaded/revised snapshots, the small bounded Missouri outcome population, selected sampling, unmeasured confounding, ambient-exposure mismatch, retrospective CDC reporting, no isolate genome/traceability link and no prospective intervention validation. Ablation can show changed held-out scores within this study; it cannot establish biological causation or prove that an added data source improves real-world safety.

Run on Windows

First, extract the whole ZIP to a writable folder such as Documents. Open the extracted AEGIS-Judges folder. Do not start files from inside the ZIP.

  1. Install Python 3.13 (64-bit) if needed. Use the official Python Windows downloads and select a Python 3.13 installer. The dependency lock was tested with Python 3.13. Use the normal installer, not the embeddable package.
  2. Open 02_Application. Double-click Setup-Judges-Windows.cmd once. It creates a local Python environment and downloads the pinned dependencies. Allow setup to finish; internet is required for this step.
  3. Double-click Start-Judges-Windows.cmd. It starts a fresh isolated simulated session and attempts to open your browser after verifying the server. Keep its terminal window open.
  4. Open http://127.0.0.1:8001/?mode=rehearsal if the browser did not open. This link works only while the application is running on your own computer.

No Node.js, GitHub account, AWS account or API key is required for this prebuilt demo. Setup requires internet; background map tiles also require internet. The core demo uses labeled, dated source fixtures and estimated routing. It does not claim current public-feed connectivity.

To stop, press Ctrl+C in the application terminal. Starting the judge launcher again creates a new scenario session. Do not close it while reviewing the dashboard.

Terminal commands or macOS/Linux

Run commands from 02_Application. On Windows PowerShell:

py -3.13 scripts/judge_demo.py setup
.venv\Scripts\python.exe scripts/judge_demo.py run --port 8001 --open-browser

On macOS/Linux with Python 3.13 installed:

python3.13 scripts/judge_demo.py setup
.venv/bin/python scripts/judge_demo.py run --port 8001 --open-browser

Windows and Linux have their own recorded verification evidence. macOS setup commands are supplied; no physical macOS test is claimed.

Troubleshooting

The browser link will not open

Start the application first and keep its terminal open. Opening frontend/index.html directly does not run the app. If port 8001 is occupied, run .venv\Scripts\python.exe scripts/judge_demo.py run --port 8002 --open-browser from 02_Application and use the printed URL. The launcher does not stop another program.

Python or a dependency is missing

Install Python 3.13, then run Setup-Judges-Windows.cmd again. Check the setup terminal for the actual error. A failed package download may require an internet connection or institutional IT assistance. The PDFs remain readable without setup.

Map background or live source is unavailable

The core evidence and planning workflows use included dated snapshots and labeled estimates. Map tiles require internet and may be blocked by a network. Source timestamps and fallbacks remain visible. This is not a hosted public website or a live sensor deployment.

# Structure steering

`backend/` holds modular implementation; `frontend/` holds interfaces; `scripts/` holds reproducible commands; `config/` holds API definitions; `data/manifests/` holds raw inventory; `data/processed/` holds derived tables; `reports/` holds measured outputs; `docs/` holds scientific and implementation limits.

Unknown data sources are inventoried without automatic pooling. Source-specific ingestion errors should remain attributable to their source. No real recall match may be inferred from a fictional lot identifier.

Codex-prepared steering; not evidence of actual Kiro usage.
